# Contexto de negócio público

Esta pasta começa sem conteúdo de negócio. Copie `_modelo.md` para `<modulo>.md`, usando o nome do módulo do pedido em minúsculas, sem acentos e com hífens. Bruno preencherá cada recurso com conteúdo público.

O MCP lê somente o arquivo do módulo marcado `🟢 PÚBLICO`, sem material interno, confidencial ou dados pessoais. Sem esse arquivo, o modelo pode propor seções de negócio; o juiz marca as frases como **a confirmar** para revisão na prévia. A publicação exige revisão humana das pendências.
