# Contexto de negócio público

Esta pasta começa sem conteúdo de negócio. Um arquivo `.md` curado por uma pessoa pode ser usado pelo MCP somente quando estiver marcado `🟢 PÚBLICO` e não contiver material interno, confidencial ou dados pessoais. Cada afirmação publicada precisa citar um trecho literal do arquivo. Se faltar fonte, a seção correspondente vira pendência e é omitida.
