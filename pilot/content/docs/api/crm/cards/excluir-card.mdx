Marca um card como inativo. O histórico é preservado; use restauração para reativá-lo.

## Parâmetros de rota

<Params>
<Param name="id" type="int">
ID do card.
</Param>
</Params>

## Exemplo

<CodeTabs labels={["cURL", "Node", "Python", "HTTP"]}>

```bash
curl -X DELETE "https://apiv3.ihelpchat.com/api/v2/crm/card/8821" \
  -H "Authorization: Bearer $IHELP_TOKEN"
```

```js
const res = await fetch('https://apiv3.ihelpchat.com/api/v2/crm/card/8821', {
  method: 'DELETE',
  headers: { Authorization: `Bearer ${process.env.IHELP_TOKEN}` },
});

console.log(res.status);
```

```python
import os, requests

r = requests.delete(
    "https://apiv3.ihelpchat.com/api/v2/crm/card/8821",
    headers={"Authorization": f"Bearer {os.environ['IHELP_TOKEN']}"},
    timeout=15,
)
print(r.status_code)
```

```http
DELETE /api/v2/crm/card/8821 HTTP/1.1
Host: apiv3.ihelpchat.com
Authorization: Bearer $IHELP_TOKEN
```

</CodeTabs>

## Erros

| HTTP | `error` | Quando |
|---|---|---|
| 401 | - | Token ausente, inválido ou expirado |
| 403 | - | Permissão apenas de visualização no funil da etapa |
| 404 | - | Card não encontrado ou sem permissão para visualizar |
