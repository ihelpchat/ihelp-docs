Filtra cards do funil com busca textual, status, etapa, responsável, datas e paginação. Honra as mesmas regras de permissão do board.

## Parâmetros de rota

<Params>
<Param name="funnelId" type="int">
ID do funil.
</Param>
</Params>

## Corpo da requisição

<Params>
<Param name="generalText" type="string">
Texto para busca em título, descrição, contato, valor, status e notas.
</Param>
<Param name="status" type="int">
`1` Aberto, `2` Em andamento, `3` Ganho, `4` Perdido, `5` Cancelado.
</Param>
<Param name="stageId" type="int">
ID da etapa.
</Param>
<Param name="responsibleId" type="int">
ID do responsável.
</Param>
<Param name="startDate" type="datetime">
Data de início (UTC).
</Param>
<Param name="endDate" type="datetime">
Data de término (UTC).
</Param>
<Param name="priority" type="int">
Prioridade: `1` Baixa, `2` Média, `3` Alta, `4` Urgente.
</Param>
<Param name="tags" type="string[]">
Tags associadas aos contatos.
</Param>
<Param name="overdue" type="bool">
Se true, retorna apenas cards com tarefas vencidas.
</Param>
<Param name="isFavorite" type="bool">
Se true, retorna apenas favoritos do usuário.
</Param>
<Param name="page" type="int">
Página (1-indexed). Padrão: 1.
</Param>
<Param name="pageSize" type="int">
Itens por página. Padrão: 20.
</Param>
</Params>

Para filtros avançados aninhados (AND/OR), use [Carregar board filtrado](/api/crm/cards/carregar-board-com-filtro). Mais campos estão disponíveis em [Filtro de cards](/api/crm/filtro-de-cards).

## Erros

| HTTP | `error` | Quando |
|---|---|---|
| 400 | - | Funil inexistente ou parâmetro de filtro inválido |
| 401 | - | Token ausente, inválido ou expirado |
| 403 | - | Sem acesso ao funil |
