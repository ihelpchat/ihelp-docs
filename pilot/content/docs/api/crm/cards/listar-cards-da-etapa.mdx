Lista os cards de uma etapa com paginação. É o scroll infinito de cada coluna do kanban: o corpo leva a página e, se quiser, os mesmos filtros do board.

## Parâmetros de rota

<Params>
<Param name="stageId" type="int">
ID da etapa (ex: `1700`).
</Param>
</Params>

## Corpo da requisição

Todos os campos são opcionais: `{}` retorna a primeira página com 20 cards.

<Params>
<Param name="page" type="int">
Página, começando em `1`. Padrão: `1`.
</Param>
<Param name="pageSize" type="int">
Cards por página. Padrão: `20`.
</Param>
<Param name="generalText" type="string">
Busca em título, descrição, nome, ID e número do contato, valor, status e notas.
</Param>
<Param name="status" type="int">
`1` Aberto, `2` Em andamento, `3` Ganho, `4` Perdido, `5` Cancelado.
</Param>
<Param name="responsibleId" type="int">
ID do usuário responsável.
</Param>
<Param name="filterTree" type="object">
Filtro avançado com grupos E/OU aninhados. Sintaxe e demais campos em [Filtro de cards](/api/crm/filtro-de-cards).
</Param>
</Params>

## Exemplo

Terceira página da etapa `1700`, 10 cards por página:

<CodeTabs labels={["cURL", "Node", "Python", "HTTP"]}>

```bash
curl -X POST "https://apiv3.ihelpchat.com/api/v2/crm/funnelstage/1700/cards" \
  -H "Authorization: Bearer $IHELP_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"page": 3, "pageSize": 10}'
```

```js
const res = await fetch('https://apiv3.ihelpchat.com/api/v2/crm/funnelstage/1700/cards', {
  method: 'POST',
  headers: { Authorization: `Bearer ${process.env.IHELP_TOKEN}`, 'Content-Type': 'application/json' },
  body: JSON.stringify({ page: 3, pageSize: 10 }),
});

const { data, pagination } = await res.json();
console.log(pagination.totalItems, data[0].title);
```

```python
import os, requests

r = requests.post(
    "https://apiv3.ihelpchat.com/api/v2/crm/funnelstage/1700/cards",
    json={"page": 3, "pageSize": 10},
    headers={"Authorization": f"Bearer {os.environ['IHELP_TOKEN']}"},
    timeout=15,
)
body = r.json()
print(body["pagination"]["totalItems"], body["data"][0]["title"])
```

## Campos relevantes

<Fields>
<Field name="pagination.hasNext">
`true` enquanto houver próxima página. Com `pageSize: 10` e `totalItems: 87`, são 9 páginas: a 9ª traz 7 cards e `hasNext: false`.
</Field>
<Field name="data[].id">
ID numérico do card (ex: `163346`).
</Field>
<Field name="data[].tags">
Tags do contato em lista (ex: `["PARTICULAR", "ENDOCRINOLOGIA"]`). Vem `[]` quando não há tag. `tagsRaw` é a mesma lista separada por `||` e não vem quando está vazia.
</Field>
<Field name="data[].contactCustomFields">
Campos personalizados do contato com valor (ex: `ID PipeRun` = `10020030`). Só vem quando o contato tem algum preenchido.
</Field>
<Field name="data[].hasOverdueTask">
`true` quando o card tem tarefa vencida.
</Field>
</Fields>

## Erros

| HTTP | Corpo | Quando |
|---|---|---|
| 400 | `Erro ao buscar cards por estágio: ...` | Filtro inválido (ex: `filterTree` malformado) |
| 401 | - | Token ausente, inválido ou expirado, ou usuário sem acesso ao funil da etapa |
| 404 | `Estágio não encontrado` | Etapa inexistente |
