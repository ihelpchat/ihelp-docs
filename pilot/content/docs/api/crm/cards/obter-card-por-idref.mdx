Busca um card pelo idRef (UUID opaco), usado em URLs públicas. Retorna os mesmos dados da busca por ID.

## Parâmetros de rota

<Params>
<Param name="idRef" type="string">
UUID opaco do card.
</Param>
</Params>

## Exemplo

<CodeTabs labels={["cURL", "Node", "Python", "URL"]}>

```bash
curl https://apiv3.ihelpchat.com/api/v2/crm/card/by-idref/0b8f7c52-1a3e-4d7f-9f7e-5a0c2d1b9e33 \
  -H "Authorization: Bearer $IHELP_TOKEN"
```

```js
const res = await fetch('https://apiv3.ihelpchat.com/api/v2/crm/card/by-idref/0b8f7c52-1a3e-4d7f-9f7e-5a0c2d1b9e33', {
  headers: { Authorization: `Bearer ${process.env.IHELP_TOKEN}` },
});

console.log(res.status);
```

```python
import os, requests

r = requests.get(
    "https://apiv3.ihelpchat.com/api/v2/crm/card/by-idref/0b8f7c52-1a3e-4d7f-9f7e-5a0c2d1b9e33",
    headers={"Authorization": f"Bearer {os.environ['IHELP_TOKEN']}"},
    timeout=15,
)
print(r.status_code)
```


## Erros

| HTTP | `error` | Quando |
|---|---|---|
| 401 | - | Token ausente, inválido ou expirado |
| 404 | - | Card não encontrado ou sem permissão para visualizar |
