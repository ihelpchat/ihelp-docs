Edita um item do catálogo: nome, descrição, tipo, SKU ou preço.

## Parâmetros de rota

<Params>
<Param name="id" type="int">
ID do item no catálogo.
</Param>
</Params>

## Corpo da requisição

<Params>
<Param name="name" type="string" required>
Nome do item, até 120 caracteres.
</Param>
<Param name="description" type="string">
Descrição, até 500 caracteres.
</Param>
<Param name="type" type="int" required>
`1` = Produto, `2` = Serviço.
</Param>
<Param name="sku" type="string">
Código do item, até 40 caracteres. Único por empresa (sem diferenciar maiúsculas).
</Param>
<Param name="price" type="decimal" required>
Preço em R$, mínimo `0`.
</Param>
</Params>

## Exemplo

```bash
curl -X PUT "https://apiv3.ihelpchat.com/api/v2/crm/catalog/10" \

  -d '{

  "description": "Até 15 usuários, suporte prioritário",
```

## Regras

SKU repetido (diferente do atual) responde `409 Conflict`. Atualizar um item do catálogo **não** afeta propostas já salvas; nome e preço de cada proposta são cópias. Requer **administrador da empresa** e o módulo de propostas ativo.

## Erros

| HTTP | `error` | Quando |
|---|---|---|
| 400 | - | Validação de campos |
| 401 | - | Usuário não é administrador |
| 403 | - | Módulo de propostas desligado |
| 404 | - | Item inexistente ou de outra empresa |
| 409 | - | SKU já existe em outro item |
