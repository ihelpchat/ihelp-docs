Importa múltiplos itens do catálogo em um lote, criando ou atualizando conforme necessário.

## Corpo da requisição

<Params>
<Param name="items[]" type="object" required>
Array de itens a importar. Cada item segue as mesmas regras de criação.
</Param>
<Param name="items[].name" type="string" required>
Nome do item, até 120 caracteres.
</Param>
<Param name="items[].description" type="string">
Descrição, até 500 caracteres.
</Param>
<Param name="items[].type" type="int" required>
`1` = Produto, `2` = Serviço.
</Param>
<Param name="items[].sku" type="string">
Código do item, até 40 caracteres. Linha sem SKU sempre cria um item novo.
</Param>
<Param name="items[].price" type="decimal" required>
Preço em R$, mínimo `0`.
</Param>
<Param name="updateBySku" type="bool">
Se `true`, SKU que já existe é atualizado; se `false`, é ignorado. Padrão `false`.
</Param>
</Params>

```bash
  -H "Content-Type: application/json" \
  -d '{
  "items": [
    {
      "name": "Plano Pro (anual)",
      "type": 2,
      "sku": "PRO-12M",
      "price": 800
    },
    {
      "name": "Implantação",
      "type": 2,
      "price": 300
    }
  ],
  "updateBySku": true
}'
```

## Regras

- Linha inválida é contada em `ignored` e o lote continua.
- SKU repetido **dentro do mesmo lote** vale a primeira linha, as demais são ignoradas.
- Linha sem SKU sempre cria um item novo.
- Sem limite de linhas por chamada, mas prefira lotes de até 500.
- Requer **administrador da empresa** e o módulo de propostas ativo.

## Erros

| HTTP | `error` | Quando |
|---|---|---|
| 400 | - | Validação de campos |
| 401 | - | Usuário não é administrador |
| 403 | - | Módulo de propostas desligado |
