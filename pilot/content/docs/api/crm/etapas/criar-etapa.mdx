Cria uma nova etapa em um funil com título, cor, descrição opcional e posição.

Campos obrigatórios: `title`, `color` e `funnelId`. A cor deve estar no formato hexadecimal `#RRGGBB`. Exige nível Admin ou Owner no funil, ou ser administrador da empresa.

## Corpo da requisição

<Params>
<Param name="title" type="string" required>
Título da etapa. Máximo 100 caracteres.
</Param>
<Param name="color" type="string" required>
Cor em formato hexadecimal #RRGGBB. Exemplo: #F59E0B
</Param>
<Param name="funnelId" type="int" required>
ID do funil onde a etapa será criada. Funil inexistente responde 400.
</Param>
<Param name="description" type="string">
Descrição da etapa. Máximo 500 caracteres.
</Param>
<Param name="order" type="int">
Posição na sequência. 0 ou omitido coloca no final.
</Param>
</Params>

## Exemplo

<CodeTabs labels={["cURL", "Node", "Python", "HTTP"]}>

```bash
curl -X POST "https://apiv3.ihelpchat.com/api/v2/crm/funnelstage" \
  -H "Authorization: Bearer $IHELP_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "title": "Negociação",
  "description": "Proposta enviada, aguardando retorno",
  "color": "#F59E0B",
  "order": 0,
  "funnelId": 12
}'
```

## Erros

| HTTP | `error` | Quando |
|---|---|---|
| 400 | - | Título vazio, cor inválida, funil inexistente, ou funnelId fora do intervalo |
| 401 | - | Token ausente, inválido ou expirado |
| 403 | - | Sem permissão Admin/Owner no funil |
