Lista cards de uma etapa com filtros avançados aninhados, para scroll infinito com AND/OR complexos.

Este é o endpoint de scroll infinito do kanban quando filtros avançados estão ativos. O corpo aceita o `filterTree` com operadores AND/OR. Para filtros simples, prefira [Paginar cards da etapa](/api/crm/etapas/paginar-cards-da-etapa) com GET.

## Parâmetros de rota

<Params>
<Param name="stageId" type="int">
ID da etapa.
</Param>
</Params>

## Corpo da requisição

<Params>
<Param name="page" type="int">
Número da página (1-based). Padrão: 1.
</Param>
<Param name="pageSize" type="int">
Itens por página. Padrão: 50. Máximo: 500.
</Param>
<Param name="generalText" type="string">
Busca textual em título, descrição e contato.
</Param>
<Param name="status" type="int">
Status do card (1 Aberto, 2 Em andamento, 3 Ganho, 4 Perdido, 5 Cancelado).
</Param>
<Param name="responsibleId" type="int">
ID do usuário responsável.
</Param>
<Param name="filterTree" type="object">
Árvore de filtros avançados com operadores AND/OR aninhados. Ver [Filtro de cards](/api/crm/filtro-de-cards).
</Param>
</Params>

Corpo vazio (`{}`) ou `filterTree` vazio retorna todos os cards da etapa. Ver [Filtro de cards](/api/crm/filtro-de-cards) para sintaxe completa do `filterTree`.

## Exemplo

<CodeTabs labels={["cURL", "Node", "Python", "HTTP"]}>

```bash
curl -X POST "https://apiv3.ihelpchat.com/api/v2/crm/funnelstage/101/cards" \
  -H "Authorization: Bearer $IHELP_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "page": 1,
  "pageSize": 50,
  "filterTree": {
    "op": "AND",
    "groups": [],
    "conditions": []
  }
}'
```

## Erros

| HTTP | `error` | Quando |
|---|---|---|
| 400 | - | Sintaxe inválida no filterTree |
| 401 | - | Token ausente, inválido ou expirado |
| 403 | - | Sem acesso ao funil da etapa |
| 404 | - | Etapa inexistente |
