Lista os cards abertos de uma etapa com paginação, respeitando filtros rápidos.

Use este endpoint para carregar cards com paginação simples (filtros rápidos apenas). Para filtros avançados com `filterTree`, use [Paginar com filtro](/api/crm/etapas/paginar-cards-com-filtro) com POST.

## Parâmetros de rota

<Params>
<Param name="stageId" type="int">
ID da etapa.
</Param>
</Params>

## Parâmetros de consulta

<Params>
<Param name="page" type="int" required={false}>
Número da página (1-based). Padrão: 1.
</Param>
<Param name="pageSize" type="int" required={false}>
Itens por página. Padrão: 50. Máximo: 500.
</Param>
<Param name="generalText" type="string" required={false}>
Busca textual em título, descrição e contato.
</Param>
<Param name="status" type="int" required={false}>
Status do card (1 Aberto, 2 Em andamento, 3 Ganho, 4 Perdido, 5 Cancelado).
</Param>
<Param name="responsibleId" type="int" required={false}>
ID do usuário responsável.
</Param>
</Params>
