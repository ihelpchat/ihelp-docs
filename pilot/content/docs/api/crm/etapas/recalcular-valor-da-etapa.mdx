Recalcula o valor total agregado da etapa somando os valores estimados de todos os cards abertos.

## Parâmetros de rota

<Params>
<Param name="stageId" type="int">
ID da etapa.
</Param>
</Params>

## Exemplo

<CodeTabs labels={["cURL", "Node", "Python", "HTTP"]}>

```bash
curl -X PUT "https://apiv3.ihelpchat.com/api/v2/crm/funnelstage/101/recalculate-value" \
  -H "Authorization: Bearer $IHELP_TOKEN"
```

```js
const res = await fetch('https://apiv3.ihelpchat.com/api/v2/crm/funnelstage/101/recalculate-value', {
  method: 'PUT',
  headers: { Authorization: `Bearer ${process.env.IHELP_TOKEN}` },
});

console.log(res.status);
```

```python
import os, requests

r = requests.put(
    "https://apiv3.ihelpchat.com/api/v2/crm/funnelstage/101/recalculate-value",
    headers={"Authorization": f"Bearer {os.environ['IHELP_TOKEN']}"},
    timeout=15,
)
print(r.status_code)
```
