Reordena as etapas do funil alterando suas posições.

O array precisa conter exatamente todas as etapas ativas do funil. Faltando ou sobrando alguma, a resposta é 400. Cada posição no array define o novo `order` de cada etapa (0, 1, 2...).

## Parâmetros de rota

<Params>
<Param name="funnelId" type="int">
ID do funil.
</Param>
</Params>

## Corpo da requisição

<Params>
<Param name="[].id" type="int" required>
ID da etapa.
</Param>
<Param name="[].order" type="int" required>
Posição desejada (não usado internamente; a posição final é a do índice no array).
</Param>
</Params>

## Erros

| HTTP | `error` | Quando |
|---|---|---|
| 400 | - | Array incompleto, com etapas inexistentes, ou ordem duplicada |
| 401 | - | Token ausente, inválido ou expirado |
| 403 | - | Sem permissão Admin/Owner no funil |
| 404 | - | Funil inexistente |
