Cria um novo filtro salvo para um funil. A configuração é um JSON serializado de até 10 KB contendo as regras de filtro.

## Corpo da requisição

<Params>
<Param name="name" type="string" required>
Nome do filtro, até 100 caracteres.
</Param>
<Param name="filterConfig" type="string" required>
Configuração do filtro como JSON serializado em texto, até 10 KB. JSON inválido responde `400` com `FilterConfig must be valid JSON.`. Veja [Filtro de cards](/api/crm/filtro-de-cards) para a estrutura.
</Param>
<Param name="funnelId" type="int" required>
ID do funil ao qual o filtro pertence.
</Param>
</Params>

## Exemplo

<CodeTabs labels={["cURL", "Node", "Python", "HTTP"]}>

```bash
curl -X POST "https://apiv3.ihelpchat.com/api/v2/crm/saved-filters" \
  -H "Authorization: Bearer $IHELP_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "name": "Quentes acima de 5 mil",
  "filterConfig": "{\"filterTree\":{\"op\":\"AND\",\"conditions\":[{\"fieldId\":\"temperature\",\"fieldType\":\"select\",\"op\":\"any\",\"value\":[\"quente\"]},{\"fieldId\":\"estimatedValue\",\"fieldType\":\"number\",\"op\":\"gte\",\"value\":5000}]}}",
  "funnelId": 12
}'
```

## Erros

| HTTP | `error` | Quando |
|---|---|---|
| 400 | - | Nome vazio, `filterConfig` inválido ou muito grande, `funnelId` ausente ou inválido, JSON de configuração com sintaxe incorreta |
| 401 | - | Token ausente, inválido ou expirado |
