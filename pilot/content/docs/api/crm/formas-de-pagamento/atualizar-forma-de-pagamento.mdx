Atualiza uma forma de pagamento existente.

## Parâmetros de rota

<Params>
<Param name="id" type="int">
ID da forma de pagamento.
</Param>
</Params>

## Corpo da requisição

<Params>
<Param name="name" type="string">
Nome, até 120 caracteres.
</Param>
<Param name="discountPct" type="decimal">
Desconto percentual de `0` a `100`.
</Param>
<Param name="allowsInstallments" type="bool">
Se aceita parcelamento.
</Param>
<Param name="maxInstallments" type="int">
De `1` a `24`.
</Param>
<Param name="firstDueDays" type="int">
Dias até a primeira parcela, de `0` a `365`.
</Param>
<Param name="dueMode" type="int">
`1` = intervalo em dias, `2` = dia fixo.
</Param>
<Param name="intervalDays" type="int">
Intervalo entre parcelas em dias, de `1` a `365`.
</Param>
<Param name="fixedDueDay" type="int">
Dia fixo do mês entre `1` e `31`.
</Param>
<Param name="sortOrder" type="int">
Ordem de exibição, mínimo `0`.
</Param>
</Params>

## Regras

- Apenas administradores da empresa podem atualizar. Usuário não-admin recebe `401` sem corpo.
- O módulo de propostas deve estar ativo. Caso contrário, recebe `403`.
- ID inexistente ou de outra empresa responde `404`.

## Erros

| HTTP | `error` | Quando |
|---|---|---|
| 400 | - | Validação falha |
| 401 | - | Não é administrador da empresa |
| 403 | - | Módulo de propostas não está ativo |
| 404 | - | ID não encontrado ou de outra empresa |
