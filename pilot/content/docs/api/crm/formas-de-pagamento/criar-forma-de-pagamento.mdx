Cria uma nova forma de pagamento: nome, desconto, parcelamento, prazos e ordem de exibição.

## Corpo da requisição

<Params>
<Param name="name" type="string" required>
Nome da forma de pagamento, até 120 caracteres.
</Param>
<Param name="discountPct" type="decimal">
Desconto percentual de `0` a `100`. Informativo: é copiado para a proposta, mas não altera o total.
</Param>
<Param name="allowsInstallments" type="bool">
Se aceita parcelamento.
</Param>
<Param name="maxInstallments" type="int">
De `1` a `24`. Com parcelamento precisa ser ao menos `2`; sem parcelamento precisa ser exatamente `1`. Padrão `1`.
</Param>
<Param name="firstDueDays" type="int">
Dias até a primeira parcela, de `0` a `365`.
</Param>
<Param name="dueMode" type="int">
`1` = intervalo em dias, `2` = dia fixo do mês. Padrão `1`.
</Param>
<Param name="intervalDays" type="int">
Intervalo entre parcelas em dias, de `1` a `365`. Obrigatório com parcelamento e `dueMode: 1`.
</Param>
<Param name="fixedDueDay" type="int">
Dia fixo do mês entre `1` e `31`. Obrigatório com parcelamento e `dueMode: 2`.
</Param>
<Param name="sortOrder" type="int">
Ordem de exibição, mínimo `0`.
</Param>
</Params>

## Regras

- Apenas administradores da empresa podem criar. Usuário não-admin recebe `401` sem corpo.
- O módulo de propostas deve estar ativo. Caso contrário, recebe `403`.
- Validação: com parcelamento, `maxInstallments` deve ser `>= 2`; com `dueMode: 1`, `intervalDays` é obrigatório; com `dueMode: 2`, `fixedDueDay` é obrigatório.

## Erros

| HTTP | `error` | Quando |
|---|---|---|
| 400 | - | Validação falha (nome vazio, valores inválidos, regras de parcelamento) |
| 401 | - | Não é administrador da empresa |
| 403 | - | Módulo de propostas não está ativo |
