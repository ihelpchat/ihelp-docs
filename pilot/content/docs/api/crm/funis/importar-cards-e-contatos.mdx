Importa cards e contatos em lote para um funil

## Corpo da requisição

<Params>
<Param name="[].nome" type="string" required>
Nome do contato (título do card será Atendimento - Nome)
</Param>
<Param name="[].telefones" type="array" required>
Array de telefones. Ao menos um. O primeiro localiza um contato existente
</Param>
<Param name="[].emails" type="array" required>
Array de emails. Pode ser vazio, mas deve estar presente
</Param>
<Param name="[].funil" type="string" required>
Nome exato do funil, diferenciando maiúsculas
</Param>
<Param name="[].etapa" type="string" required>
Nome da etapa dentro do funil, sem diferenciar maiúsculas
</Param>
<Param name="[].departamento" type="string" required={false}>
Nome exato do departamento. Vira o departamento do contato
</Param>
<Param name="[].usuario" type="string" required={false}>
Email do usuário. Vira responsável pelo contato, só se departamento bateu
</Param>
</Params>

Corpo é um array, uma linha por card. Linhas com erro de funil/etapa são puladas silenciosamente, mas o contato já foi criado ou atualizado. A importação não respeita a trava de contato do funil.

## Exemplo

<CodeTabs labels={["cURL", "Node", "Python", "HTTP"]}>

```bash
curl -X POST "https://apiv3.ihelpchat.com/api/v2/crm/funnel/import-card-contact" \
  -H "Authorization: Bearer $IHELP_TOKEN" \
  -H "Content-Type: application/json" \
  -d '[
  {
    "nome": "Ana Souza",
    "telefones": [
      "5517981259808"
    ],
    "emails": [
      "compras@acme.com.br"
    ],
    "funil": "Funil de Vendas",
    "etapa": "Novo lead",
    "departamento": "Comercial",
    "usuario": "joao@suaempresa.com.br"
  }
]'
```

## Erros

| HTTP | `error` | Quando |
|---|---|---|
| 400 | `Bad Request` | Corpo inválido ou array vazio |
| 401 | `Unauthorized` | Token ausente ou inválido |
