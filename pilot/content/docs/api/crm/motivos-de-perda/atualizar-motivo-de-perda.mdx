Atualiza parcialmente um motivo de perda. Apenas administradores podem atualizar.

## Parâmetros de rota

<Params>
<Param name="id" type="int" required>
ID do motivo.
</Param>
</Params>

## Corpo da requisição

<Params>
<Param name="reason" type="string">
Nova descrição, até 200 caracteres. Se não informado, preserva valor atual.
</Param>
<Param name="isDefault" type="bool">
Novo valor padrão. Se não informado, preserva.
</Param>
<Param name="orderIndex" type="int">
Novo índice. Se não informado, preserva.
</Param>
</Params>

## Exemplo

<CodeTabs labels={["cURL", "Node", "Python", "HTTP"]}>

```bash
curl -X PATCH "https://apiv3.ihelpchat.com/api/v2/crm/loss-reasons/4" \
  -H "Authorization: Bearer $IHELP_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "reason": "Preço muito acima do orçamento",
  "orderIndex": 3
}'
```

```js
const res = await fetch('https://apiv3.ihelpchat.com/api/v2/crm/loss-reasons/4', {
  method: 'PATCH',
  headers: { Authorization: `Bearer ${process.env.IHELP_TOKEN}`, 'Content-Type': 'application/json' },
  body: JSON.stringify({
    "reason": "Preço muito acima do orçamento",
    "orderIndex": 3
  }),
});

console.log(res.status);
```

```python
import os, requests

r = requests.patch(
    "https://apiv3.ihelpchat.com/api/v2/crm/loss-reasons/4",
    json={
        "reason": "Preço muito acima do orçamento",
        "orderIndex": 3,
    },
    headers={"Authorization": f"Bearer {os.environ['IHELP_TOKEN']}"},
    timeout=15,
)
print(r.status_code)
```

## Erros

| HTTP | `error` | Quando |
|---|---|---|
| 400 | - | Motivo maior que 200 caracteres |
| 401 | - | Token ausente, inválido ou expirado |
| 403 | - | Usuário não é administrador |
| 404 | - | Motivo não encontrado |
