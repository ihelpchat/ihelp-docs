Remove um motivo de perda. Registros históricos de cards que usaram este motivo são preservados. Apenas administradores podem deletar.

## Parâmetros de rota

<Params>
<Param name="id" type="int" required>
ID do motivo.
</Param>
</Params>

## Exemplo

<CodeTabs labels={["cURL", "Node", "Python", "HTTP"]}>

```bash
curl -X DELETE "https://apiv3.ihelpchat.com/api/v2/crm/loss-reasons/4" \
  -H "Authorization: Bearer $IHELP_TOKEN"
```

```js
const res = await fetch('https://apiv3.ihelpchat.com/api/v2/crm/loss-reasons/4', {
  method: 'DELETE',
  headers: { Authorization: `Bearer ${process.env.IHELP_TOKEN}` },
});

console.log(res.status);
```

```python
import os, requests

r = requests.delete(
    "https://apiv3.ihelpchat.com/api/v2/crm/loss-reasons/4",
    headers={"Authorization": f"Bearer {os.environ['IHELP_TOKEN']}"},
    timeout=15,
)
print(r.status_code)
```

```http
DELETE /api/v2/crm/loss-reasons/4 HTTP/1.1
Host: apiv3.ihelpchat.com
Authorization: Bearer $IHELP_TOKEN
```

## Erros

| HTTP | `error` | Quando |
|---|---|---|
| 401 | - | Token ausente, inválido ou expirado |
| 403 | - | Usuário não é administrador |
| 404 | - | Motivo não encontrado |
