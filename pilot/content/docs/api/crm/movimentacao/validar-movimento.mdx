Pre-check de movimentação: verifica se um card pode ser movido para outra etapa sem alterar seu estado, informando pendências obrigatórias se houver.

Use este endpoint antes de executar [Mover card](/api/crm/movimentacao/mover-card) para descobrir se existem pendências. Se retornar `409`, apresente ao usuário a opção de contornar com `force=true`.

## Parâmetros de rota

<Params>
<Param name="id" type="int">
ID do card.
</Param>
</Params>

## Parâmetros de consulta

<Params>
<Param name="targetStageId" type="int" required>
ID da etapa de destino. Deve estar no mesmo funil.
</Param>
</Params>

## Regras

- Este é um **pré-check que não altera estado**. Serve para a interface decidir se mostra um modal de confirmação.
- Recomendação: não force() sem passar por UI, pois nega pendências reais.
- Se voltar `canMove: true`, [Mover card](/api/crm/movimentacao/mover-card) sem `force` executará sem 409.

## Erros

| HTTP | `error` | Quando |
|---|---|---|
| 401 | - | Token ausente, inválido ou expirado |
| 403 | - | Permissão apenas de visualização no funil da etapa |
| 404 | - | Card não encontrado, de outra empresa, ou etapa não existe |
