Atualiza uma anotação existente, alterando título, descrição e anexo.

## Parâmetros de rota

<Params>
<Param name="id" type="int">
ID do card.
</Param>
<Param name="noteId" type="int">
ID da anotação a atualizar.
</Param>
</Params>

## Corpo da requisição

<Params>
<Param name="title" type="string">
Novo título. Campo omitido é apagado.
</Param>
<Param name="description" type="string">
Novo corpo da anotação.
</Param>
<Param name="mediaUrl" type="string">
Nova URL do anexo. Campo omitido é apagado.
</Param>
<Param name="mediaType" type="string">
Novo tipo MIME.
</Param>
<Param name="mediaName" type="string">
Novo nome do arquivo.
</Param>
<Param name="mediaSize" type="int">
Novo tamanho em bytes.
</Param>
<Param name="mediaThumbnail" type="string">
Nova URL da miniatura.
</Param>
</Params>

## Regras

Campos omitidos são apagados (ex.: remover um anexo é omitir `mediaUrl`). A privacidade (`isPrivate`) **não pode ser alterada** em uma atualização; ela é definida apenas na criação. O campo `cardId` e `isPrivate` no corpo são ignorados.

## Erros

| HTTP | `error` | Quando |
|---|---|---|
| 401 | - | Token ausente, inválido ou expirado |
| 403 | - | Permissão apenas de visualização no funil da etapa |
| 404 | - | Card ou anotação não encontrados, ou de outra empresa |
