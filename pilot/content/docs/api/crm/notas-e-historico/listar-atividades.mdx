Lista histórico e tarefas vinculadas ao card mesclados e ordenados por data (mais recentes primeiro), com suporte a paginação.

## Parâmetros de rota

<Params>
<Param name="id" type="int">
ID do card.
</Param>
</Params>

## Parâmetros de consulta

<Params>
<Param name="page" type="int" required={false}>
Número da página (começa em 1). Se omitido ou sem `pageSize`, retorna a lista completa.
</Param>
<Param name="pageSize" type="int" required={false}>
Quantidade de itens por página.
</Param>
</Params>

## Regras

Esta rota mescla dois tipos de registro: histórico do card e tarefas. Cada item tem `isHistory` para indicar seu tipo. Use [Listar histórico](/api/crm/notas-e-historico/listar-historico) para apenas histórico.

## Erros

| HTTP | `error` | Quando |
|---|---|---|
| 401 | - | Token ausente, inválido ou expirado |
| 403 | - | Permissão apenas de visualização no funil da etapa |
| 404 | - | Card não encontrado ou de outra empresa |
