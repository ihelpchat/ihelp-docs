Atualiza os dados do perfil da empresa: razão social, CNPJ, contato, configurações de propostas e texto de apresentação.

## Corpo da requisição

<Params>
<Param name="legalName" type="string" required>
Razão social, até 150 caracteres.
</Param>
<Param name="cnpj" type="string">
CNPJ, até 20 caracteres, formato livre.
</Param>
<Param name="email" type="string">
E-mail válido, até 100 caracteres.
</Param>
<Param name="phone" type="string">
Telefone, até 20 caracteres.
</Param>
<Param name="introText" type="string">
Texto de abertura da proposta, até 1000 caracteres.
</Param>
<Param name="introEnabled" type="bool">
Se o texto de abertura é exibido.
</Param>
<Param name="paymentsEnabled" type="bool">
Se o bloco de condições de pagamento aparece nas propostas.
</Param>
<Param name="shippingEnabled" type="bool">
Se o bloco de frete e transportadora aparece nas propostas.
</Param>
<Param name="pdfMergeEnabled" type="bool">
Se um modelo de PDF é anexado ao documento.
</Param>
<Param name="pdfMergePosition" type="int">
`1` = modelo antes da proposta, `2` = depois. Padrão `1`.
</Param>
<Param name="pdfMergeTemplateId" type="int">
ID do modelo de PDF padrão. Deve existir na empresa.
</Param>
</Params>

## Regras

- Apenas administradores da empresa podem atualizar. Usuário não-admin recebe `401` sem corpo.
- O módulo de propostas deve estar ativo. Caso contrário, recebe `403`.
- Modelo de PDF inválido (ID inexistente ou de outra empresa) responde `400` com mensagem em `dados`.

## Erros

| HTTP | `error` | Quando |
|---|---|---|
| 400 | - | Modelo de PDF inválido, validação falha ou erro ao processar |
| 401 | - | Não é administrador da empresa |
| 403 | - | Módulo de propostas não está ativo |
