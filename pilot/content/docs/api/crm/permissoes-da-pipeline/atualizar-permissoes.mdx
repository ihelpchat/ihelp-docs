Sincroniza as permissões da pipeline: substitui a lista completa de membros. Quem não estiver na lista perde acesso.

## Parâmetros de rota

<Params>
<Param name="id" type="int" required>
ID da pipeline.
</Param>
</Params>

## Corpo da requisição

<Params>
<Param name="members[]" type="object[]" required>
Array de membros e permissões.
</Param>
<Param name="members[].userId" type="int" required>
ID do usuário da empresa.
</Param>
<Param name="members[].level" type="string">
`none`, `view`, `edit` ou `admin`. `owner` vira `admin`. Padrão `edit`.
</Param>
<Param name="members[].onlyOwnCards" type="bool">
Para edit: usuário vê só seus cards. Omitido mantém valor atual. Sempre false para admin e owner.
</Param>
</Params>

Campos `name`, `email`, `isTenantAdmin` e `isOwner` aparecem no GET mas são ignorados no PATCH.

## Regras

Dono e administradores da empresa nunca são alterados por este endpoint — permanecem com acesso independentemente da lista. Quem sai da regra de visibilidade (ex.: troca de `public` para `private`) também é mantido se tiver permissão explícita.

## Erros

| HTTP | `error` | Quando |
|---|---|---|
| 400 | - | Payload vazio ou `members` não informado |
| 401 | - | Token ausente, inválido ou expirado |
| 403 | - | Sem permissão de admin na pipeline |
| 404 | - | Pipeline não encontrada |
