Duplica a pipeline com etapas e regras. Opcionalmente copia os cards junto.

## Parâmetros de rota

<Params>
<Param name="id" type="int" required>
ID da pipeline a duplicar.
</Param>
</Params>

## Corpo da requisição

<Params>
<Param name="newName" type="string" required>
Nome da nova pipeline, mínimo 2 caracteres, único na empresa.
</Param>
<Param name="includeCards" type="bool">
Se true, copia os cards também. Padrão false.
</Param>
</Params>

## Exemplo

<CodeTabs labels={["cURL", "Node", "Python", "HTTP"]}>

```bash
curl -X POST "https://apiv3.ihelpchat.com/api/v2/crm/pipelines/12/duplicate" \
  -H "Authorization: Bearer $IHELP_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "newName": "Vendas B2B (cópia)",
  "includeCards": false
}'
```

```js
const res = await fetch('https://apiv3.ihelpchat.com/api/v2/crm/pipelines/12/duplicate', {
  method: 'POST',
  headers: { Authorization: `Bearer ${process.env.IHELP_TOKEN}`, 'Content-Type': 'application/json' },
  body: JSON.stringify({
    "newName": "Vendas B2B (cópia)",
    "includeCards": false
  }),
});

console.log(res.status);
```

```python
import os, requests

r = requests.post(
    "https://apiv3.ihelpchat.com/api/v2/crm/pipelines/12/duplicate",
    json={
        "newName": "Vendas B2B (cópia)",
        "includeCards": False,
    },
    headers={"Authorization": f"Bearer {os.environ['IHELP_TOKEN']}"},
    timeout=15,
)
print(r.status_code)
```

## Erros

| HTTP | `error` | Quando |
|---|---|---|
| 400 | - | Nome vazio, menos de 2 caracteres, ou duplicado na empresa |
| 401 | - | Token ausente, inválido ou expirado |
| 403 | - | Sem permissão de admin na pipeline |
| 404 | - | Pipeline não encontrada |
