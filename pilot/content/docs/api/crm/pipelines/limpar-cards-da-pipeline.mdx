Remove todos os cards da pipeline, incluindo abertos, ganhos e perdidos. Operação destrutiva e irreversível.

## Parâmetros de rota

<Params>
<Param name="id" type="int" required>
ID da pipeline.
</Param>
</Params>

## Exemplo

<CodeTabs labels={["cURL", "Node", "Python", "HTTP"]}>

```bash
curl -X POST "https://apiv3.ihelpchat.com/api/v2/crm/pipelines/12/clear-cards" \
  -H "Authorization: Bearer $IHELP_TOKEN"
```

```js
const res = await fetch('https://apiv3.ihelpchat.com/api/v2/crm/pipelines/12/clear-cards', {
  method: 'POST',
  headers: { Authorization: `Bearer ${process.env.IHELP_TOKEN}` },
});

console.log(res.status);
```

```python
import os, requests

r = requests.post(
    "https://apiv3.ihelpchat.com/api/v2/crm/pipelines/12/clear-cards",
    headers={"Authorization": f"Bearer {os.environ['IHELP_TOKEN']}"},
    timeout=15,

```

## Regras

Usuários com restrição de apenas seus cards veem apenas os cards que são seus removidos. A operação emite SSE para atualizar o board em tempo real.

## Erros

| HTTP | `error` | Quando |
|---|---|---|
| 401 | - | Token ausente, inválido ou expirado |
| 403 | - | Sem permissão de admin na pipeline |
| 404 | - | Pipeline não encontrada |
