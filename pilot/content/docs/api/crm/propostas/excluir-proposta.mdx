Exclui uma proposta do card e recalcula o valor estimado.

## Parâmetros de rota

<Params>
<Param name="id" type="int">
ID da proposta.
</Param>
</Params>

## Exemplo

<CodeTabs labels={["cURL", "Node", "Python", "HTTP"]}>

```bash
curl -X DELETE "https://apiv3.ihelpchat.com/api/v2/crm/proposals/123" \
  -H "Authorization: Bearer $IHELP_TOKEN"
```

```js
const res = await fetch('https://apiv3.ihelpchat.com/api/v2/crm/proposals/123', {
  method: 'DELETE',
  headers: { Authorization: `Bearer ${process.env.IHELP_TOKEN}` },
});

console.log(res.status);
```

```python
import os, requests

r = requests.delete(
    "https://apiv3.ihelpchat.com/api/v2/crm/proposals/123",
    headers={"Authorization": f"Bearer {os.environ['IHELP_TOKEN']}"},
    timeout=15,
)
print(r.status_code)
```

```http
DELETE /api/v2/crm/proposals/123 HTTP/1.1
Host: apiv3.ihelpchat.com
Authorization: Bearer $IHELP_TOKEN
```

</CodeTabs>

## Regras

A exclusão é soft delete (marcada como deletada, não removida do banco). O `estimatedValue` do card é recalculado com o total das propostas restantes que não foram rejeitadas.

## Erros

| HTTP | `error` | Quando |
|---|---|---|
| 401 | - | Token ausente, inválido ou expirado |
| 403 | - | Módulo de propostas desligado |
| 404 | - | Proposta inexistente ou de outra empresa |
