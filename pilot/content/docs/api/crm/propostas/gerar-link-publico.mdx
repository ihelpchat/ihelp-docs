Gera ou retorna um link público para que o cliente visualize e responda a proposta.

## Parâmetros de rota

<Params>
<Param name="id" type="int">
ID da proposta.
</Param>
</Params>

## Exemplo

<CodeTabs labels={["cURL", "Node", "Python", "HTTP"]}>

```bash
curl -X POST "https://apiv3.ihelpchat.com/api/v2/crm/proposals/123/link" \
  -H "Authorization: Bearer $IHELP_TOKEN"
```

```js
const res = await fetch('https://apiv3.ihelpchat.com/api/v2/crm/proposals/123/link', {
  method: 'POST',
  headers: { Authorization: `Bearer ${process.env.IHELP_TOKEN}` },
});

console.log(res.status);
```

```python
import os, requests

r = requests.post(
    "https://apiv3.ihelpchat.com/api/v2/crm/proposals/123/link",
    headers={"Authorization": f"Bearer {os.environ['IHELP_TOKEN']}"},
    timeout=15,
)
print(r.status_code)
```

```http
POST /api/v2/crm/proposals/123/link HTTP/1.1
Host: apiv3.ihelpchat.com
Authorization: Bearer $IHELP_TOKEN
```

</CodeTabs>

## Regras

Na primeira chamada gera um novo token e link. Nas chamadas seguintes devolve o mesmo link já gerado. O link deixa de abrir quando a proposta vence ou é excluída.

## Erros

| HTTP | `error` | Quando |
|---|---|---|
| 401 | - | Token ausente, inválido ou expirado |
| 403 | - | Módulo de propostas desligado |
| 404 | - | Proposta inexistente ou de outra empresa |
