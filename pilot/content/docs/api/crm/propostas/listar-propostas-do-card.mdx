## Parâmetros de rota

<Params>
<Param name="cardId" type="int">
ID do card.
</Param>
</Params>

## Exemplo

<CodeTabs labels={["cURL", "Node", "Python", "URL"]}>

```bash
curl https://apiv3.ihelpchat.com/api/v2/crm/proposals/card/8821 \
  -H "Authorization: Bearer $IHELP_TOKEN"
```

```js
const res = await fetch('https://apiv3.ihelpchat.com/api/v2/crm/proposals/card/8821', {

console.log(res.status);
```

```python
import os, requests

r = requests.get(

    headers={"Authorization": f"Bearer {os.environ['IHELP_TOKEN']}"},
    timeout=15,

print(r.status_code)
```
