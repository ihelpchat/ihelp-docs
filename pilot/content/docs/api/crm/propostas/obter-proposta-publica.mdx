Obtém o documento da proposta conforme visto pelo cliente no link público, sem IDs internos.

## Parâmetros de rota

<Params>
<Param name="idRef" type="uuid">
Identificador único da proposta no link público.
</Param>
</Params>

## Parâmetros de consulta

<Params>
<Param name="t" type="string" required>
Token do link público gerado com [`POST /proposals/{id}/link`](/api/crm/propostas/gerar-link-publico).
</Param>
</Params>

  --data-urlencode "t=9f2c7e8b1a4d5f6c9e0a2b3d4e5f6a7b8c9d0e1"

## Regras

- **Sem autenticação**: rota pública. Token errado, proposta vencida, excluída ou inexistente devolvem o mesmo `404` sem corpo (de propósito).
- Inclui dados da empresa (nome, telefone, e-mail) e o texto de abertura (se habilitado no perfil).
- **Mostra apenas** os campos relevantes para o cliente; IDs internos, timestamps de auditoria e dados sensíveis não aparecem.

## Erros

| HTTP | `error` | Quando |
|---|---|---|
| 404 | - | Token errado, proposta vencida, excluída ou inexistente (mesmo `404` para não distinguir) |
