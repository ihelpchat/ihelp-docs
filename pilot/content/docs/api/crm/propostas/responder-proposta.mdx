Registra a resposta do cliente ao aceitar ou rejeitar a proposta via link público.

## Parâmetros de rota

<Params>
<Param name="idRef" type="uuid">
Identificador único da proposta no link público.
</Param>
</Params>

## Parâmetros de consulta

<Params>
<Param name="t" type="string" required>
Token do link público gerado com [`POST /proposals/{id}/link`](/api/crm/propostas/gerar-link-publico).
</Param>
</Params>

## Corpo da requisição

<Params>
<Param name="result" type="int" required>
`1` = Aceita (proposta fica Fechada), `2` = Rejeita (proposta fica Rejeitada).
</Param>
</Params>

## Exemplo

  -H "Content-Type: application/json" \
  -d '{
  "result": 1

## Regras

- **Sem autenticação**: esta é uma rota pública. Token errado, proposta vencida, excluída ou inexistente devolvem o mesmo `404` sem corpo (de propósito, para não vazar a existência).
- **Idempotente**: se a proposta já foi respondida ou o vendedor já a marcou como Fechada/Rejeitada, a chamada devolve `200` com o documento atual e não muda nada.
- **Rate limit**: máximo 10 chamadas por minuto por IP e proposta. Acima disso: `429` com `{ "dados": { "message": "Muitas tentativas. Tente novamente em breve.", "retryAfterSeconds": 42 } }`.
- O card **não** muda de etapa quando a proposta é respondida.

## Erros

| HTTP | `error` | Quando |
|---|---|---|
| 400 | - | Resposta inválida: `result` não é `1` nem `2` |
| 404 | - | Token errado, proposta vencida, excluída ou inexistente (mesmo `404` para não distinguir) |
| 429 | - | Rate limit: mais de 10 tentativas por minuto |
