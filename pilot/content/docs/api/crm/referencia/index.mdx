Use esta seção quando precisar consultar o contrato de um recurso do CRM. Para um fluxo guiado de movimentação, comece pela [visão geral do CRM](/api/crm/visao-geral).

## Recursos

- [Cards](/api/crm/referencia/cards): campos, estados e operações disponíveis para oportunidades.
- [Funis e etapas](/api/crm/referencia/funis-e-etapas): estrutura usada para organizar e movimentar cards.
- [Pipelines](/api/crm/referencia/pipelines): consulta e organização das pipelines do CRM.
- [Automações e filtros](/api/crm/referencia/automacoes-e-filtros): regras e critérios aplicáveis aos fluxos.

## Antes de integrar

Obtenha os IDs no mesmo ambiente em que fará a alteração, autentique a requisição com uma credencial de integração e teste primeiro com um card controlado. Não copie IDs entre empresas ou ambientes.

Os guias explicam a sequência completa; as páginas desta referência detalham os recursos e campos usados em cada etapa.
</Callout>
