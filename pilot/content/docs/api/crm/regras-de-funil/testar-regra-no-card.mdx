Testa se uma regra se aplica a um card específico, avaliando as condições sem disparar as ações em produção.

## Parâmetros de rota

<Params>
<Param name="ruleId" type="int">
ID da regra a testar.
</Param>
<Param name="cardId" type="int">
ID do card a testar a regra contra.
</Param>
</Params>

## Exemplo

<CodeTabs labels={["cURL", "Node", "Python", "HTTP"]}>

```bash
curl -X POST "https://apiv3.ihelpchat.com/api/v2/crm/funnelrule/evaluate/4/opportunity/8821" \
  -H "Authorization: Bearer $IHELP_TOKEN"
```
