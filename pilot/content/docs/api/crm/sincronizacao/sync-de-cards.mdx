Sincroniza um lote de cards com o servidor (criação, atualização, exclusão lógica ou restauração).

<Callout type="warn" title="Uso interno">
Este endpoint implementa a sincronização incremental do próprio app iHelp e não faz parte da API de integração.
</Callout>

## Corpo da requisição

<Params>
<Param name="[]" type="Card[]" required>
Array de cards completos com todos os campos da entidade Card. IDs de cards existentes atualizam; novos são criados. Campos nulos são preservados. Se o usuário é restrito a funis, cards alheios são ignorados; cards novos herdam o criador como proprietário.
</Param>
</Params>

Cards com `id: 0` ou omitido são criados. Se `isActive: false`, marca o card como removido (soft delete). O servidor descarta cards do request que pertencem a outros usuários (no caso de acesso restrito).
