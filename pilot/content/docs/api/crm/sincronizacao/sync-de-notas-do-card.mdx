Sincroniza um lote de notas de um card específico.

<Callout type="warn" title="Uso interno">
Este endpoint implementa a sincronização incremental do próprio app iHelp e não faz parte da API de integração.
</Callout>

## Parâmetros de rota

<Params>
<Param name="cardId" type="int">
ID do card ao qual as notas pertencem.
</Param>
</Params>

## Corpo da requisição

<Params>
<Param name="[]" type="CardNote[]" required>
Array de notas completas com todos os campos da entidade CardNote. O `cardId` de cada item é forçado ao cardId da rota. IDs existentes atualizam; novos são criados.
</Param>
</Params>

Notas com `isActive: false` são marcadas como removidas (soft delete). Se o card não existe ou pertence a outro usuário (em acesso restrito), a requisição retorna `404`.

## Regras

Este é o endpoint legado (CardController). Para novo código, prefira [Sync V2 de notas](/api/crm/sincronizacao/sync-v2-de-notas).

## Erros

| HTTP | `error` | Quando |
|---|---|---|
| 400 | - | Card não existe neste tenant |
| 401 | - | Token ausente, inválido ou expirado |
| 404 | - | Card não encontrado ou pertence a outro usuário (acesso restrito) |
