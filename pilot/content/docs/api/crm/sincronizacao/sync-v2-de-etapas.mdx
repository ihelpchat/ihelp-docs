Sincroniza um lote de etapas de funis com o servidor (criação, atualização ou exclusão lógica).

<Callout type="warn" title="Uso interno">
Este endpoint implementa a sincronização incremental do próprio app iHelp e não faz parte da API de integração.
</Callout>

## Corpo da requisição

<Params>
<Param name="[]" type="FunnelStage[]" required>
Array de etapas completas com todos os campos da entidade FunnelStage. IDs de etapas existentes atualizam; novos são criados. Campos nulos são preservados.
</Param>
</Params>

Etapas com `isActive: false` são desativadas (soft delete). Se `id: 0` ou omitido, uma nova etapa é criada. O `funnelId` referencia um funil existente.

| 401 | - | Token ausente, inválido ou expirado |
