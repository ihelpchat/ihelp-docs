Sincroniza um lote de funis (pipeline) com o servidor (criação, atualização ou exclusão lógica).

<Callout type="warn" title="Uso interno">
Este endpoint implementa a sincronização incremental do próprio app iHelp e não faz parte da API de integração.
</Callout>

## Corpo da requisição

<Params>
<Param name="[]" type="Funnel[]" required>
Array de funis completos com todos os campos da entidade Funnel. IDs de funis existentes atualizam; novos são criados. Campos nulos são preservados.
</Param>
</Params>

Funis com `isActive: false` são desativados (soft delete). Se `id: 0` ou omitido, um novo funil é criado.

## Exemplo

<CodeTabs labels={["cURL", "Node", "Python", "HTTP"]}>

```bash
curl -X POST "https://apiv3.ihelpchat.com/api/v2/crm/sync/funnel/batch" \
  -H "Authorization: Bearer $IHELP_TOKEN" \
  -H "Content-Type: application/json" \
  -d '[
  {
    "id": 12,
    "businessId": 3,
    "title": "Funil de Vendas",
    "description": "Pipeline de vendas principal",
    "isDefault": true,
    "isActive": true,
    "contactLock": true,
    "createdDate": "2026-01-15T08:00:00Z",
    "updatedAt": "2026-09-25T10:30:00Z"
  },
  {
    "id": 13,
    "businessId": 3,
    "title": "Suporte",
    "description": "Funil de atendimento ao cliente",
    "isDefault": false,

    "contactLock": false,
    "createdDate": "2026-02-20T09:00:00Z",
    "updatedAt": "2026-09-24T14:15:00Z"
  }
]'
```
