Sincroniza um lote de registros de histórico de cards com o servidor (criação, atualização ou exclusão lógica).

<Callout type="warn" title="Uso interno">
Este endpoint implementa a sincronização incremental do próprio app iHelp e não faz parte da API de integração. Versão melhorada (V2) da [Sync de histórico](/api/crm/sincronizacao/sync-de-historico-do-card).
</Callout>

## Corpo da requisição

<Params>
<Param name="[]" type="CardHistory[]" required>
Array de registros de histórico completos com todos os campos da entidade CardHistory. IDs existentes atualizam; novos são criados. Se o card de um histórico não existe ou pertence a outro usuário (acesso restrito), o histórico é descartado; cards inexistentes não recusam o lote inteiro.
</Param>
</Params>

Históricos com `isActive: false` são marcados como removidos (soft delete). Se um `cardId` referencia um card inexistente, esse histórico é descartado mas não causa erro no lote.

## Erros

| HTTP | `error` | Quando |
|---|---|---|
| 400 | - | Lista vazia ou inválida |
| 401 | - | Token ausente, inválido ou expirado |
| 404 | - | Todos os históricos do lote pertencem a cards alheios (acesso restrito) |
