Sincroniza um lote de notas de cards com o servidor (criação, atualização ou exclusão lógica).

<Callout type="warn" title="Uso interno">
Este endpoint implementa a sincronização incremental do próprio app iHelp e não faz parte da API de integração. Versão melhorada (V2) da [Sync de notas](/api/crm/sincronizacao/sync-de-notas-do-card).
</Callout>

## Corpo da requisição

<Params>
<Param name="[]" type="CardNote[]" required>
Array de notas completas com todos os campos da entidade CardNote. IDs existentes atualizam; novos são criados. Se o card de uma nota não existe ou pertence a outro usuário (acesso restrito), a nota é descartada; cards inexistentes não recusam o lote inteiro.
</Param>
</Params>

Notas com `isActive: false` são marcadas como removidas (soft delete). Se um `cardId` referencia um card inexistente, essa nota é descartada mas não causa erro no lote.

## Erros

| HTTP | `error` | Quando |
|---|---|---|
| 400 | - | Lista vazia ou inválida |
| 401 | - | Token ausente, inválido ou expirado |
| 404 | - | Todas as notas do lote pertencem a cards alheios (acesso restrito) |
