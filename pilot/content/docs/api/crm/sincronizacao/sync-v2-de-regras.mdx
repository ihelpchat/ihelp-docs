Sincroniza um lote de regras de funis com o servidor (criação, atualização ou exclusão lógica).

<Callout type="warn" title="Uso interno">
Este endpoint implementa a sincronização incremental do próprio app iHelp e não faz parte da API de integração.
</Callout>

## Corpo da requisição

<Params>
<Param name="[]" type="FunnelRule[]" required>
Array de regras completas com todos os campos da entidade FunnelRule. IDs de regras existentes atualizam; novos são criados. Campos nulos são preservados.
</Param>
</Params>

Regras com `isActive: false` são desativadas (soft delete). Se `id: 0` ou omitido, uma nova regra é criada. O `funnelId` referencia um funil existente.
