Envia um evento de teste para todos os usuários conectados via SSE (Server-Sent Events). Apenas para administradores.

<Callout type="warn" title="Uso interno">
Este é um endpoint de teste para eventos em tempo real. Requer role de Administrador. Envia eventos em broadcast para todos os clientes SSE conectados.
</Callout>

## Corpo da requisição

<Params>
<Param name="eventType" type="string" required>
Tipo do evento, ex.: `system_notification`, `maintenance_alert`, `test_broadcast`. Pode ser qualquer string.
</Param>
<Param name="data" type="object" required>
Payload do evento em objeto JSON. Estrutura arbitrária conforme o tipo de evento.
</Param>
</Params>

## Exemplo

<CodeTabs labels={["cURL", "Node", "Python", "HTTP"]}>

```bash
curl -X POST "https://apiv3.ihelpchat.com/api/v2/crm/sse/test/all" \
  -H "Authorization: Bearer $IHELP_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "eventType": "system_notification",
  "data": {
    "message": "Sistema em manutenção em 10 minutos",
    "severity": "warning",
    "startTime": "2026-09-25T14:00:00Z",
    "durationMinutes": 30
  }
}'
```

## Regras

Este endpoint requer autenticação com role `Admin`. O evento é entregue a todos os usuários em todas as suas conexões SSE ativas, independentemente da empresa. Clientes SSE devem estar conectados ao endpoint Connect para receber o evento.

## Erros

| HTTP | `error` | Quando |
|---|---|---|
| 400 | - | Body vazio ou inválido |
| 401 | - | Token ausente, inválido ou expirado |
| 403 | - | Usuário não tem role de Administrador |
