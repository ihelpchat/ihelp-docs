Envia um evento de teste para o usuário autenticado via SSE (Server-Sent Events).

<Callout type="warn" title="Uso interno">
Este é um endpoint de teste para eventos em tempo real. Envia eventos apenas para o usuário que fez a requisição.
</Callout>

## Corpo da requisição

<Params>
<Param name="eventType" type="string" required>
Tipo do evento, ex.: `card_updated`, `card_moved`, `note_added`. Pode ser qualquer string.
</Param>
<Param name="data" type="object" required>
Payload do evento em objeto JSON. Estrutura arbitrária conforme o tipo de evento.
</Param>
</Params>

## Exemplo

<CodeTabs labels={["cURL", "Node", "Python", "HTTP"]}>

```bash
curl -X POST "https://apiv3.ihelpchat.com/api/v2/crm/sse/test/user" \
  -H "Authorization: Bearer $IHELP_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "eventType": "card_updated",
  "data": {
    "cardId": 8821,
    "title": "Proposta ACME",
    "stageId": 102,
    "status": 2,
    "timestamp": "2026-09-25T13:20:41Z"
  }
}'
```

```js
const res = await fetch('https://apiv3.ihelpchat.com/api/v2/crm/sse/test/user', {
  method: 'POST',
  headers: { Authorization: `Bearer ${process.env.IHELP_TOKEN}`, 'Content-Type': 'application/json' },
  body: JSON.stringify({
    "eventType": "card_updated",
    "data": {
      "cardId": 8821,
      "title": "Proposta ACME",
      "stageId": 102,
      "status": 2,
      "timestamp": "2026-09-25T13:20:41Z"
    }
  }),
});

console.log(res.status);
```

```python
import os, requests

r = requests.post(
    "https://apiv3.ihelpchat.com/api/v2/crm/sse/test/user",
    json={
        "eventType": "card_updated",
        "data": {
            "cardId": 8821,
            "title": "Proposta ACME",
            "stageId": 102,
            "status": 2,
            "timestamp": "2026-09-25T13:20:41Z",
        },
    },
    headers={"Authorization": f"Bearer {os.environ['IHELP_TOKEN']}"},
    timeout=15,
)
print(r.status_code)
```

## Regras

O evento é entregue apenas ao usuário do token, em todas as suas abas/dispositivos conectados. O cliente SSE deve estar em conexão ativa com o endpoint Connect para receber o evento.

## Erros

| HTTP | `error` | Quando |
|---|---|---|
| 400 | - | Body vazio ou inválido |
| 401 | - | Token ausente, inválido ou expirado |
