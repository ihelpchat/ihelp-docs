Restaura um card ganho ou perdido de volta ao board, revertendo seu status para aberto.

## Parâmetros de rota

<Params>
<Param name="id" type="int">
ID do card.
</Param>
</Params>

## Exemplo

<CodeTabs labels={["cURL", "Node", "Python", "HTTP"]}>

```bash
curl -X POST "https://apiv3.ihelpchat.com/api/v2/crm/card/8821/restore" \
  -H "Authorization: Bearer $IHELP_TOKEN"
```

```js
const res = await fetch('https://apiv3.ihelpchat.com/api/v2/crm/card/8821/restore', {
  method: 'POST',
  headers: { Authorization: `Bearer ${process.env.IHELP_TOKEN}` },
});

console.log(res.status);
```

```python
import os, requests

r = requests.post(
    "https://apiv3.ihelpchat.com/api/v2/crm/card/8821/restore",
    headers={"Authorization": f"Bearer {os.environ['IHELP_TOKEN']}"},
    timeout=15,
)
print(r.status_code)
```

```http
POST /api/v2/crm/card/8821/restore HTTP/1.1
Host: apiv3.ihelpchat.com
Authorization: Bearer $IHELP_TOKEN
```

## Erros

| HTTP | `error` | Quando |
|---|---|---|
| 401 | - | Token ausente, inválido ou expirado |
| 403 | - | Permissão apenas de visualização no funil da etapa |
| 404 | - | Card não encontrado, de outra empresa, ou não é ganho nem perdido |
