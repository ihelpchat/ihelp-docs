Reordena os modelos de tarefa de uma etapa

## Parâmetros de rota

<Params>
<Param name="stageId" type="int">
Identificador da etapa
</Param>
</Params>

## Corpo da requisição

<Params>
<Param name="orderedIds" type="array" required>
Array com IDs dos modelos na nova ordem
</Param>
</Params>

A lista deve conter exatamente todos os modelos ativos da etapa. Cada modelo recebe a posição em que aparece no array (primeiro vira 0, segundo vira 1, etc).

## Exemplo

<CodeTabs labels={["cURL", "Node", "Python", "HTTP"]}>

```bash
curl -X POST "https://apiv3.ihelpchat.com/api/v2/crm/stages/101/task-templates/reorder" \
  -H "Authorization: Bearer $IHELP_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "orderedIds": [
    2,
    1,
    3
  ]
}'
```

```js
const res = await fetch('https://apiv3.ihelpchat.com/api/v2/crm/stages/101/task-templates/reorder', {
  method: 'POST',
  headers: { Authorization: `Bearer ${process.env.IHELP_TOKEN}`, 'Content-Type': 'application/json' },
  body: JSON.stringify({
    "orderedIds": [
      2,
      1,
      3
    ]
  }),
});

console.log(res.status);
```

```python
import os, requests

r = requests.post(
    "https://apiv3.ihelpchat.com/api/v2/crm/stages/101/task-templates/reorder",
    json={
        "orderedIds": [
            2,
            1,
            3,
        ],
    },
    headers={"Authorization": f"Bearer {os.environ['IHELP_TOKEN']}"},
    timeout=15,
)
print(r.status_code)
```

## Erros

| HTTP | `error` | Quando |
|---|---|---|
| 400 | `Bad Request` | Array incompleto ou com IDs desconhecidos, ou não contém todos os modelos da etapa |
| 401 | `Unauthorized` | Token ausente ou inválido |
| 403 | `Forbidden` | Usuário não tem permissão |
| 404 | `Not Found` | Etapa não existe |
