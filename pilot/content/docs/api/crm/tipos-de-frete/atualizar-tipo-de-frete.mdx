Atualiza um tipo de frete: nome, previsão de entrega, valor padrão e transportadora.

## Parâmetros de rota

<Params>
<Param name="id" type="int">
ID do tipo de frete.
</Param>
</Params>

## Corpo da requisição

<Params>
<Param name="name" type="string">
Nome, até 120 caracteres.
</Param>
<Param name="deliveryEstimate" type="string">
Previsão de entrega, até 120 caracteres.
</Param>
<Param name="chargesFee" type="bool">
Se o valor de frete entra no total.
</Param>
<Param name="defaultFee" type="decimal">
Valor padrão de frete, mínimo `0`.
</Param>
<Param name="requiresCarrier" type="bool">
Se a transportadora é obrigatória.
</Param>
<Param name="defaultCarrierId" type="int">
ID da transportadora sugerida.
</Param>
<Param name="sortOrder" type="int">
Ordem de exibição, mínimo `0`.
</Param>
</Params>

## Regras

- Apenas administradores da empresa podem atualizar. Usuário não-admin recebe `401` sem corpo.
- O módulo de propostas deve estar ativo. Caso contrário, recebe `403`.
- ID inexistente ou de outra empresa responde `404`.

## Erros

| HTTP | `error` | Quando |
|---|---|---|
| 400 | - | Validação falha (transportadora inválida, etc) |
| 401 | - | Não é administrador da empresa |
| 403 | - | Módulo de propostas não está ativo |
| 404 | - | ID não encontrado ou de outra empresa |
