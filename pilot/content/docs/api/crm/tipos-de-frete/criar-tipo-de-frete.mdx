Cria um novo tipo de frete: nome, previsão de entrega, valor padrão e transportadora associada.

## Corpo da requisição

<Params>
<Param name="name" type="string" required>
Nome do tipo de frete, até 120 caracteres.
</Param>
<Param name="deliveryEstimate" type="string">
Previsão padrão de entrega, até 120 caracteres.
</Param>
<Param name="chargesFee" type="bool">
Se o valor de frete entra no total da proposta.
</Param>
<Param name="defaultFee" type="decimal">
Valor padrão de frete. Obrigatório (mínimo `0`) quando `chargesFee: true`.
</Param>
<Param name="requiresCarrier" type="bool">
Indica que a proposta deve informar transportadora. O servidor não bloqueia propostas sem ela.
</Param>
<Param name="defaultCarrierId" type="int">
ID da transportadora sugerida. `null` = escolher na proposta.
</Param>
<Param name="sortOrder" type="int">
Ordem de exibição, mínimo `0`.
</Param>
</Params>

## Exemplo

<CodeTabs labels={["cURL", "Node", "Python", "HTTP"]}>

```bash
curl -X POST "https://apiv3.ihelpchat.com/api/v2/crm/shipping-types" \
  -H "Authorization: Bearer $IHELP_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "name": "Transportadora",
  "deliveryEstimate": "7 dias úteis",
  "chargesFee": true,
  "defaultFee": 45.9,
  "requiresCarrier": true,
  "defaultCarrierId": 4,
  "sortOrder": 0
}'
```

## Regras

- Apenas administradores da empresa podem criar. Usuário não-admin recebe `401` sem corpo.
- O módulo de propostas deve estar ativo. Caso contrário, recebe `403`.
- Transportadora padrão inválida (ID inexistente ou de outra empresa) responde `400` com mensagem em `dados`.

## Erros

| HTTP | `error` | Quando |
|---|---|---|
| 400 | - | Validação falha (nome vazio, transportadora inválida, frete necessário quando chargesFee: true) |
| 401 | - | Não é administrador da empresa |
| 403 | - | Módulo de propostas não está ativo |
