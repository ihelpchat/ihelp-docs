Cria uma nova transportadora: nome, CNPJ e unidade federativa.

## Corpo da requisição

<Params>
<Param name="name" type="string" required>
Nome da transportadora, até 120 caracteres.
</Param>
<Param name="cnpj" type="string">
CNPJ, até 20 caracteres, formato livre.
</Param>
<Param name="uf" type="string">
Sigla do estado (UF), até 2 caracteres.
</Param>
</Params>

## Exemplo

<CodeTabs labels={["cURL", "Node", "Python", "HTTP"]}>

```bash
curl -X POST "https://apiv3.ihelpchat.com/api/v2/crm/carriers" \
  -H "Authorization: Bearer $IHELP_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "name": "Rápido Express",
  "cnpj": "98.765.432/0001-10",
  "uf": "SP"
}'
```

```js
const res = await fetch('https://apiv3.ihelpchat.com/api/v2/crm/carriers', {
  method: 'POST',
  headers: { Authorization: `Bearer ${process.env.IHELP_TOKEN}`, 'Content-Type': 'application/json' },
  body: JSON.stringify({
    "name": "Rápido Express",
    "cnpj": "98.765.432/0001-10",
    "uf": "SP"
  }),
});

console.log(res.status);
```

```python
import os, requests

r = requests.post(
    "https://apiv3.ihelpchat.com/api/v2/crm/carriers",
    json={
        "name": "Rápido Express",
        "cnpj": "98.765.432/0001-10",
        "uf": "SP",
    },
    headers={"Authorization": f"Bearer {os.environ['IHELP_TOKEN']}"},
    timeout=15,
)
print(r.status_code)
```

## Regras

- Apenas administradores da empresa podem criar. Usuário não-admin recebe `401` sem corpo.
- O módulo de propostas deve estar ativo. Caso contrário, recebe `403`.

## Erros

| HTTP | `error` | Quando |
|---|---|---|
| 400 | - | Validação falha (nome vazio) |
| 401 | - | Não é administrador da empresa |
| 403 | - | Módulo de propostas não está ativo |
