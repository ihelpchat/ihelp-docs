Lista as visões salvas do usuário autenticado em uma pipeline específica. A primeira entrada é sempre a visão virtual 'Todos os cards'.

## Parâmetros de consulta

<Params>
<Param name="pipelineId" type="int" required>
ID da pipeline às visões salvas.
</Param>
</Params>

## Exemplo

<CodeTabs labels={["cURL", "Node", "Python", "URL"]}>

```bash
curl -G https://apiv3.ihelpchat.com/api/v2/crm/saved-views \
  --data-urlencode "pipelineId=12" \
  -H "Authorization: Bearer $IHELP_TOKEN"
```

```js
const params = new URLSearchParams({pipelineId: '12'});

const res = await fetch(`https://apiv3.ihelpchat.com/api/v2/crm/saved-views?${params}`, {
  headers: { Authorization: `Bearer ${process.env.IHELP_TOKEN}` },
});

console.log(res.status);
```

```python
import os, requests

r = requests.get(
    "https://apiv3.ihelpchat.com/api/v2/crm/saved-views",
    params={
        "pipelineId": 12,
    },
    headers={"Authorization": f"Bearer {os.environ['IHELP_TOKEN']}"},
    timeout=15,
)
print(r.status_code)
```

## Erros

| HTTP | `error` | Quando |
|---|---|---|
| 400 | - | Query `pipelineId` ausente ou inválida |
| 401 | - | Token ausente, inválido ou expirado |
