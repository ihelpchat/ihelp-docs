Esta seção documenta a **API do iHelp**: autenticação, busca de atendimentos,
envio de mensagens e uso de templates.

## Categorias

- **[Autenticação](/api/conceitos/autenticacao)** — envie uma credencial dedicada no header.
- **[Obter credencial](/api/conceitos/obter-token)** — solicite e armazene a credencial com segurança.
- **[Enviar mensagem comum](/api/mensagens/mensagem-comum)** — exemplo de endpoint e payload JSON.

<Callout title="Observação">
Todas as requisições exigem o header `Authorization: Bearer <token>`. Veja
**[Autenticação](/api/conceitos/autenticacao)** para detalhes.
</Callout>
