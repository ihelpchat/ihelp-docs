Exporte os contatos salvos no celular para organizar a base ou preparar uma importação no iHelp. O procedimento muda conforme o sistema do aparelho.

## Escolha seu aparelho

- [Android: exportar pelo celular ou Google Contatos](/docs/duvidas-e-dicas/download-de-lista-de-contatos/android)
- [iPhone: exportar usando iCloud e Outlook](/docs/duvidas-e-dicas/download-de-lista-de-contatos/iphone)

## Antes de importar no iHelp

Abra o arquivo exportado e confira nomes, telefones e códigos de país. Remova contatos que não devem entrar na base e mantenha uma cópia original antes de editar.

<Callout type="warn" title="Proteja os dados pessoais">
Compartilhe a lista somente com pessoas autorizadas e apague cópias temporárias após concluir a importação.
</Callout>

Para cadastrar poucos contatos, use diretamente a [Agenda de Contatos](/docs/sobre-o-sistema/agenda-de-contatos).
