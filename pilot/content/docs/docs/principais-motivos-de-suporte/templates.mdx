Template é uma mensagem modelo enviada pela API Oficial após aprovação da Meta. O cadastro e a aprovação acontecem no provedor ou no Gerenciador de Negócios da Meta.

## Pré-requisitos

- Ter um canal da API Oficial e acesso à conta usada para administrar seus templates.
- Saber o objetivo da mensagem e a categoria correspondente, sem compartilhar dados de clientes no chat.

<ProductAction id="abrir-canais" label="Abrir a tela Canais" route="/configuracoes/channel" />

1. Abra Canais e confirme se o número usado para enviar mensagens está na API Oficial.
2. Prepare o texto e as variáveis da mensagem; use uma categoria compatível com seu objetivo.
3. No provedor da API Oficial ou no Gerenciador de Negócios da Meta, envie o template para aprovação.
4. Aguarde a aprovação indicada pela Meta antes de usar o template no iHelp.

## Como confirmar

O template aparece como aprovado no gerenciador responsável e fica disponível para uso no iHelp. A Claricia não confirma o estado real de aprovação.

## Se não funcionar

Se o template for reprovado ou não aparecer no iHelp, confira o motivo indicado pela Meta e informe o estado ao atendimento. Não trate uma indicação do widget como aprovação oficial.
