# Como montar um Menu de opções no robô

<ProductAction id="abrir-robos" label="Abrir a tela Robôs" route="/bot" target="robots-create" />

1. Em **Robôs**, abra o robô que deseja configurar. No fluxo, clique no **“+”** abaixo de **“Iniciar Fluxo”** para abrir **“Adicionar bloco”**.

![Tela do iHelp: botão para adicionar bloco ao fluxo](/img/help/maThsp6oIsur9uVCylHP.png)

2. Em **“Adicionar bloco”**, escolha **“Menu de opções”**.

![Tela do iHelp: escolha Menu de opções em Adicionar bloco](/img/help/xXkjz5jUPbvh56zDmFZb.png)

3. Informe o **título do bloco** para identificá-lo no fluxo. Em **“Bloco de pergunta”**, escreva a pergunta que o cliente receberá no campo **“Mensagem”**.

![Tela do iHelp: título, Bloco de pergunta e opções](/img/help/mBfKLzgI06X5bYCR0z2i.png)

4. Clique em **“Adicionar opção +”** pelo menos uma vez. Preencha o **rótulo** de cada opção com a escolha que o cliente verá, como “Vendas” ou “Suporte”.

5. Clique em **“Adicionar bloco”** para colocar o Menu de opções no fluxo.

6. No fluxo, use o **“+”** de cada opção para conectar cada **ramificação** ao próximo bloco ou a uma **Ação**, como **“Encaminhar atendimento”**. Repita para cada escolha que você criou.

7. Confira se todas as escolhas seguem para o destino desejado e clique em **“Publicar”** para colocar o robô online. **“Salvar”** guarda o robô inativo.

![Tela do iHelp: Salvar ou Publicar o robô](/img/help/PJa3jnEjfcR7uSX0naA2.png)
