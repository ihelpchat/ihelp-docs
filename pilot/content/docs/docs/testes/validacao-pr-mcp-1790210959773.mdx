## Objetivo da validação

Este conteúdo temporário confirma que o MCP consegue criar uma branch isolada, enviar um arquivo validado e abrir um pull request para revisão humana. Nenhuma página é publicada automaticamente e nenhum conteúdo existente é alterado. O teste registra um identificador opaco do solicitante, mantém a trilha de auditoria no próprio pull request e respeita o fluxo normal do repositório. Depois da confirmação, o pull request será fechado sem merge e a branch temporária será removida para não deixar alterações de teste pendentes.
