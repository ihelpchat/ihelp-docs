A Gupshup é o provedor usado em parte das configurações da API Oficial. A conta do provedor, o aplicativo de WhatsApp e o número conectado são itens diferentes; identifique qual deles precisa ser alterado antes de começar.

## Cobrança e acompanhamento

- [Como consultar os relatórios de consumo](/docs/whatsapp-business-api/configuracao/gupshup/relatorios-de-consumo)

<Callout type="warn" title="Antes de alterar o número">
Não exclua aplicativos, números ou credenciais para tentar corrigir uma conexão. Registre o que aparece no painel e procure o suporte quando a ação puder interromper o canal.
</Callout>
